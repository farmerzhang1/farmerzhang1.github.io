We will use opam, OCaml's package manager, to install OCaml as well as various libraries and tools. We recommend (but do not require) the Visual Studio Code editor.

The Up and Running with OCaml guide on ocaml.org provides a general walkthrough, but read the platform-specific instructions below first — they reflect what has actually worked for CS 314 students. If you run into trouble, post on Piazza so we can improve these notes.

1 Install opam

The recommended path on Windows is Windows Subsystem for Linux (WSL). WSL lets you run a full GNU/Linux environment directly on Windows without a VM. Install WSL 2 if possible.

After WSL is set up, install the C build tools:

sudo apt install build-essential

Then follow the Linux / macOS / WSL tab instructions below.

If you prefer not to use WSL, follow the opam for Windows (Cygwin) installation instructions. The 64-bit graphical installer is recommended. If you get a virus-scan failure on download, try “Save link as” from an incognito browser window.

After installation completes (it takes a while), open the Cygwin terminal created in the previous step and proceed to Step 2.

⚠️ If you already had Cygwin installed, you now have two. You must use the new one (created here) for all OCaml work. See the VS Code section below for a critical note about launching VS Code from Cygwin.

Follow the instructions on opam’s official installation page, keeping the notes below in mind.

macOS

You need Xcode command-line tools. If not already installed:

xcode-select --install

WSL

Make sure unzip is installed, and disable sandboxing:

sudo apt-get install unzip
opam init --disable-sandboxing --reinit

2 Install dune, utop, and ocaml-lsp-server

Once opam is installed, run:

opam install dune utop
⚠️

If you see:

[ERROR] No switch is currently set. Please use 'opam switch' to set or install a switch

Run this first, then retry:

opam switch create ocaml-base-compiler.4.13.1
opam install dune utop

If you are using VS Code, also install the language server:

opam install ocaml-lsp-server

You can learn more from the opam usage guide, but it’s not required reading for CS 314.

3 Using Rutgers iLab (remote option)

🎓 If you’d rather not install OCaml locally, you can use the Rutgers CS iLab machines — Linux workstations maintained by the CS department with OCaml already available.

SSH into iLab using your Rutgers NetID:

ssh <NetID>@ilab.cs.rutgers.edu

Use your CS department password (not your general Rutgers password). See iLab machine status for available machines and their current load.

ℹ️ The version of OCaml installed system-wide on iLab may lag behind the latest release. If you run into version-specific issues on an assignment, post on Piazza and we’ll advise. You can also install a personal opam environment inside your iLab home directory using the Linux instructions in Step 1.

VS Code with iLab via SSH

Install the Remote-SSH extension for VS Code. This lets you edit files on iLab and use the integrated terminal, all from your local VS Code window.

4 Configure utop optional

Two optional tweaks that make utop nicer for class use:

Reduce visual clutter

By default utop shows a lot of UI chrome. To remove it, create ~/.config/utop/init.ml with these two lines: 

#utop_prompt_dummy;;
UTop.set_show_box false
mkdir -p ~/.config/utop
# then create ~/.config/utop/init.ml with the two lines above

Syntax highlighting (light mode)

Create ~/.utoprc with the following content to match the colors used in lecture:

profile: light

identifier.foreground: none
module.foreground: x-forestgreen
comment.foreground: x-firebrick
doc.foreground: x-violetred4
constant.foreground: x-darkcyan
keyword.foreground: x-purple
symbol.foreground: x-purple
string.foreground: x-violetred4
char.foreground: x-violetred4
quotation.foreground: x-purple
error.foreground: red
directive.foreground: x-mediumorchid4
parenthesis.background: light-blue
ℹ️ These colors are tuned for light mode. They will not look great in dark mode.

5 Install VS Code and the OCaml extension

Install VS Code

Download the installer for your platform from the VS Code downloads page.

ℹ️ If you installed OCaml via WSL on Windows, follow these instructions to develop in WSL using VS Code. This lets you edit WSL files in VS Code and use a WSL terminal with your OCaml installation.

Install the OCaml Platform extension

Install the OCaml Platform extension by OCaml Labs from the VS Code marketplace. Click the green Install button.

Windows (Cygwin) — important

On Windows without WSL (i.e., using Cygwin), you must launch VS Code from the Cygwin terminal, not by clicking its icon. Otherwise the language server won’t be found: 

/cygdrive/c/Users/Your\ Name/AppData/Local/Programs/Microsoft\ VS\ Code/Code.exe

To make this less painful, add an alias to your ~/.bash_profile in Cygwin:

alias vscode="/cygdrive/c/Users/Your\ Name/AppData/Local/Programs/Microsoft\ VS\ Code/Code.exe"

Replace Your\ Name with your Windows account name. After adding this, type vscode in a Cygwin terminal to launch VS Code.
